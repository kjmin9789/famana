# Famana

**파일명 앞에 프리픽스(접두어)를 붙이는 작은 macOS 메뉴 막대 앱.**

Finder에서 파일을 선택하고 **Enter → 접두어 입력 → Enter**.
기존 파일명과 확장자는 그대로 두고, 앞에 원하는 단어만 붙입니다.

```text
입력: 여행

IMG_001.jpg  →  여행 IMG_001.jpg
IMG_002.jpg  →  여행 IMG_002.jpg
일정.pdf     →  여행 일정.pdf
```

파일을 여러 개 선택해도 같은 접두어를 한 번에 붙일 수 있습니다.
키보드로 입력하거나 macOS 기본 받아쓰기로 말해서 입력하세요.

## 메뉴 막대에서 켜고 끄기

| ON | OFF |
| :---: | :---: |
| <img src="docs/images/famana-on.png" width="56" alt="Famana ON: F와 초록색 점"> | <img src="docs/images/famana-off.png" width="56" alt="Famana OFF: F와 회색 점"> |
| 초록색 점 · 접두어 입력 활성화 | 회색 점 · Finder 기본 동작 |

실제 아이콘은 18×18pt입니다. 클릭하면 켜고 꺼지며, 오른쪽 클릭하면 사용 방법·권한·받아쓰기 설정·종료 메뉴가 열립니다. 앱은 항상 OFF 상태로 시작합니다.

## 빌드하고 실행하기

- macOS 14 이상
- Xcode Command Line Tools
- 외부 라이브러리, 계정, API 키 불필요

```sh
git clone https://github.com/kjmin9789/famana.git
cd famana
bash build.sh
open build/Famana.app
```

개발 도구가 없다면 먼저 `xcode-select --install`로 설치하세요.
빌드한 Mac의 CPU 아키텍처용 앱이 생성되며, 로컬 실행용 ad-hoc 서명이 적용됩니다. App Store 배포나 Apple 공증은 포함하지 않습니다.

## 사용 방법

1. 메뉴 막대의 **F 아이콘**을 클릭합니다.
2. 최초 실행 시 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Famana를 허용합니다. 아이콘을 다시 클릭해 초록색 점으로 바꿉니다.
3. Finder에서 파일 또는 폴더를 한 개 이상 선택하고 **Enter**를 누릅니다. 최초 Finder 제어 요청도 허용합니다.
4. 입력창에서 접두어를 입력하고 결과 미리보기를 확인합니다.
5. **Enter**를 누르면 각 이름 앞에 `접두어 + 공백 하나`가 붙습니다. **Esc**는 취소입니다.

앱이 OFF이면 Finder의 기본 이름 변경 기능을 사용할 수 있습니다. 검색창이나 기존 이름 편집 칸, 수정키(Command 등)를 함께 누른 Enter는 가로채지 않습니다.

### 음성으로 입력하기

접두어 입력창에 포커스가 들어오면 **macOS 기본 받아쓰기 자동 시작을 시도**합니다. 시스템 설정 → 키보드 → 받아쓰기를 먼저 켜고 사용할 언어를 설정하세요. 최초 사용 안내가 뜨면 macOS에서 직접 허용해야 합니다.

받아쓰기 결과를 확인하고 받아쓰기를 끝낸 뒤 Enter로 적용하세요. 자동 시작이 안 되면 설정한 받아쓰기 단축키를 누르거나 키보드로 입력할 수 있습니다.

자동 시작은 macOS의 `startDictation:` 동작을 사용합니다. 공개된 타입 API가 아니므로 macOS 버전에 따라 동작이 달라질 수 있습니다. [Apple 받아쓰기 안내](https://support.apple.com/ko-kr/guide/mac-help/mh40584/mac)

### 로그인할 때 자동 실행하기

앱을 계속 둘 위치에 보관한 뒤, **시스템 설정 → 일반 → 로그인 항목**에서 `Famana.app`을 추가하세요. 로그인할 때 메뉴 막대에 나타나며, 사용하려면 아이콘을 클릭해 ON으로 전환합니다.

앱을 옮기거나 다시 빌드한 뒤 권한이 인식되지 않으면 손쉬운 사용 권한을 다시 허용하고 앱을 재실행하세요. 빌드 스크립트는 로그인 항목을 자동으로 등록하지 않습니다.

## 파일을 바꾸는 방식

- **기존 이름·확장자·파일 내용 보존:** 이름 앞에 접두어와 공백만 붙입니다.
- **덮어쓰기 방지:** 변경 전 모든 대상 이름의 충돌을 확인합니다. 충돌하면 변경을 시작하지 않습니다. 실제 변경 순간에도 덮어쓰기를 막습니다.
- **선택 항목 재확인:** 입력하는 동안 파일이 다른 파일로 교체되었는지 확인합니다.
- **중간 실패 안내:** 여러 파일의 변경은 하나의 원자적 작업이 아닙니다. 실행 중 실패하면 즉시 멈추고 변경 완료 개수를 안내합니다. 결과를 확인한 뒤 변경하지 않은 항목만 다시 선택하세요.
- **입력 검증:** 빈 접두어, `/`, `:`, 제어 문자, 너무 긴 파일명은 거부합니다.

앱 자체의 실행 취소·자동 되돌리기는 없습니다. 되돌리려면 OFF 상태에서 Finder로 이름을 수정하세요.

## 권한과 개인정보

손쉬운 사용 권한은 Finder의 Enter 입력과 입력칸 포커스를 확인하는 데 사용합니다. 자동화 권한은 Finder에서 선택한 항목의 경로를 읽는 데 사용합니다.

Famana 자체는 음성을 녹음하거나 파일·음성을 외부 API로 전송하지 않습니다. 음성 처리는 macOS 받아쓰기의 설정과 언어에 따릅니다. 계정, 서버, 분석 SDK는 없습니다.

## 검사와 구성

`bash build.sh`는 빌드 후 임시 폴더에서 단일·다중 이름 변경, 확장자와 내용 보존, 잘못된 입력, 이름 충돌, 중첩 폴더, 실행 도중 충돌 시 중단을 검사합니다. Finder 권한 및 실제 음성 인식은 사용 중 별도로 확인해야 합니다.

```sh
# 기존 빌드로 검사만 실행
build/Famana.app/Contents/MacOS/Famana --self-test

# 현재 아이콘 미리보기 생성
build/Famana.app/Contents/MacOS/Famana --export-icons build/preview
```

- `Sources/main.swift`: AppKit 메뉴 막대 UI, Finder 연동, 접두어 변경, 자체 검사
- `Assets/F.svg`: F 아이콘의 원본 벡터
- `build.sh`: 로컬 앱 번들 빌드·서명·검사

Swift와 macOS 기본 프레임워크로 구성했습니다. 생성된 앱과 빌드 로그는 저장소에 포함하지 않습니다.
